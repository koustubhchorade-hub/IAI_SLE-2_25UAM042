ChatGPT was used as a learning and development assistant during the SLE-2 experiment.

### Contributions from AI

1. **Understanding the Algorithms**

   * Helped explain the concepts of Breadth First Search (BFS) and Depth First Search (DFS).
   * Explained the difference between queue-based BFS and stack-based DFS.

2. **Python Implementation**

   * Helped understand and structure the Python implementation of BFS and DFS.
   * Assisted in understanding graph representation and traversal logic.

3. **Performance Measurement**

   * Explained how Python's `py-spy` module can be used to measure algorithm execution time.
   * Helped understand how repeated executions can be used to calculate average execution time.

4. **Nodes Expanded**

   * Helped understand how to count the number of nodes examined by each search algorithm.
   * Assisted in interpreting the relationship between nodes expanded and execution time.

5. **Result Interpretation**

   * Helped interpret the profiling results obtained from the actual program execution.
   * The final measured values were:

     * BFS average execution time: **4.6994 ms**
     * DFS average execution time: **7.0109 ms**
     * BFS nodes expanded: **15,001**
     * DFS nodes expanded: **13,625**
